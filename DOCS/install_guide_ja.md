# Android実機端末へのインストール手順書

本ドキュメントは、PCに接続したAndroid実機端末（またはエミュレータ）に対して、Ayame Keyboard をビルド・インストールするための手順をまとめたものです。

---

## 1. Android端末側の準備（USBデバッグの有効化）

実機にアプリをインストールするためには、端末側で「USBデバッグ」を有効化する必要があります。

1. **開発者向けオプションの有効化**:
   * Androidの「設定」アプリを開きます。
   * 「デバイス情報」（または「システム」>「端末情報」）を開きます。
   * **「ビルド番号」**（Build number）の項目を探し、**7回連続でタップ**します。
   * パターンやPINの入力を求められた場合は入力します。「これで開発者になりました」と表示されれば成功です。
2. **USBデバッグの許可**:
   * 「設定」アプリのトップ、または「システム」>「詳細設定」内に現れた**「開発者向けオプション」**を開きます。
   * **「USBデバッグ」**のスイッチをオンにします。

---

## 2. PC側の準備

1. **USB接続の確立**:
   * Android端末とPCをUSBケーブルで接続します。
   * 接続時、端末の画面に「このPCからのUSBデバッグを常に許可しますか？」というポップアップが表示された場合は、**「常に許可」を選択して「許可」**をタップします。
   * ※ Windowsで端末が認識されない場合は、各端末メーカー（SHARP、Sonyなど）が提供する **OEM USB ドライバ** をPCにインストールしてください。
2. **ADB (Android Debug Bridge) コマンドの確認**:
   * 本プロジェクトのインストール用ツールは `adb` を使用します。
   * PowerShell 等のターミナルで `adb devices` コマンドを実行し、接続されたデバイスのIDが表示されることを確認してください。

---

## 3. インストール手順

### 方法 A: 支援スクリプトを使用する（推奨）

本プロジェクトには、接続端末の自動検出やトラブル時の自動アンインストールをサポートする対話型スクリプトが用意されています。

1. PowerShell を開き、プロジェクトのルートディレクトリに移動します。
2. 以下のスクリプトを実行します。
   ```powershell
   ./install_to_device.ps1
   ```
3. スクリプトの指示に従います。
   * **複数台のデバイス**が接続されている場合、インストール先のデバイス番号を選択する画面が表示されます。
   * **すでに別署名（Playストア版など）のアプリ**がインストールされている場合、署名衝突エラー（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`）を検出し、自動で古いアプリをアンインストールしてクリーンインストールし直すかどうかの確認プロンプトが表示されます。

---

### 方法 B: Gradleコマンドで直接実行する

ソースコードのビルドと接続端末へのインストールをワンコマンドで実行します。

1. コマンドラインでプロジェクトのルートディレクトリに移動します。
2. 以下のコマンドを実行します。
   ```bash
   ./gradlew installDebug
   ```
3. ビルド完了後、接続されているすべてのデバイス（またはアクティブな1台）に自動でインストールされ、完了音が鳴ります。

## 4. よくあるエラーと対策（トラブルシューティング）

### ① `INSTALL_FAILED_NO_MATCHING_ABIS` でインストールが失敗する
* **症状**: 32bitアーキテクチャ（`armeabi-v7a` など）の古い端末や特定の省電力端末にインストールしようとすると、ネイティブライブラリの不一致でエラーになります。
* **原因**: AI予測変換エンジン `zenz` モジュールが 64bit 専用としてビルドされているためです。
* **対策**: 本アプリでは、現在使用していない `zenz` モジュールをビルドから除外する設定が適用されています。もし将来再有効化してこのエラーが再発した場合は、[how_to_re_enable_zenz.md](file:///c:/Users/nyama/OneDrive/APPS/JapaneseKeyboard/DOCS/how_to_re_enable_zenz.md) のアーキテクチャ制限のセクションを確認してください。

### ② `INSTALL_FAILED_UPDATE_INCOMPATIBLE` が発生する
* **症状**: インストールコマンドを実行すると、署名が競合している旨のエラーが出ます。
* **原因**: デバイスに既にインストールされているアプリ（Google Play版、または別PCでビルドしたバージョン）と、現在PCでビルドしたアプリの署名鍵（Key）が一致しないため、Androidのセキュリティ保護機能により上書きがブロックされています。
* **対策**: 
  * 方法Aの `./install_to_device.ps1` を実行している場合は、プロンプトで `y` を入力すると自動でアンインストール後に再インストールされます。
  * 手動で実行する場合は、一度端末から既存の「Ayame Keyboard」をアンインストールするか、以下のコマンドを実行してから再度インストールを試みてください。
    ```bash
    adb uninstall jp.yama3nomori.ayame
    ```
  * ※注意: アンインストールすると、ローカルに保存されている学習履歴やユーザー辞書がリセットされます。必要な場合は事前にアプリの設定画面から辞書をエクスポートしておいてください。

### ③ デバイスリストに表示されない（`adb devices` で `unauthorized` または空欄）
* **症状**: 端末を繋いでもPC側から認識されない、またはアクセス権限がないと表示されます。
* **対策**:
  * 端末側の画面ロックを解除し、「USBデバッグを許可」の画面で許可を与えてください。
  * USB接続モードが「充電のみ」になっている場合は、通知領域から「ファイル転送 / Android Auto」に変更してみてください。
  * ケーブルが充電専用ではなく「データ転送対応」のものであることを確認してください。
